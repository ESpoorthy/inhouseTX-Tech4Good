- [x] Dedicated development branch created; main preserved.
- [x] Existing Phase 0 audit/spec files retained.
- [x] Product, architecture, API, security, AI/ML, testing, deployment, known limitations and demo documentation present.
- [x] Draft Devpost description and recording materials present.

## Before Devpost submit

- [ ] Configure PayPal Sandbox app, buyer and webhook, then verify actual checkout, capture and event delivery.
- [ ] Deploy public HTTPS demo or make the local run instructions and public repository evaluator-ready.
- [ ] Push branch/repository publicly and confirm an open-source license is visible.
- [ ] Record and publish public YouTube video under three minutes; add its URL.
- [ ] Add screenshots and validate every Devpost field/URL.
- [ ] Submit before the official deadline and confirm receipt.
