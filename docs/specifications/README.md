# Phase 0 specifications

The [paypal-inhouse-tx](paypal-inhouse-tx/) folder preserves the initial requirements, design and implementation task plan created during Phase 0.

They are retained for traceability. The current implementation and operational guidance in the surrounding `docs/` files are the source of truth where the early proposal differs from the implemented application. These documents originated in a Kiro specification workflow; reading or maintaining them does not require Kiro.
