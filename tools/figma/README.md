# Figma utilities

These scripts are optional Figma-plugin/editor-context utilities used to construct or update the InHouseTX design file. They are not browser application code and are not required at runtime.

- `create_screen_frames.js`: constructs desktop screen frames and reusable visual examples.
- `create_mobile_frames.js`: constructs mobile/tablet layouts and state examples.

Run only inside the authorised Figma plugin/editor environment with the matching design file open. Review the target page and node IDs before executing. The canonical design is linked from the repository README.
