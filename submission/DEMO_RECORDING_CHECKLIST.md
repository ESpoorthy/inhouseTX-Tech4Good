# Recording and publication checklist

- [ ] Re-run tests and manual local smoke test on the exact revision being recorded.
- [ ] Use labelled demo fixtures; verify any PayPal row is backed by a real verified Sandbox event.
- [ ] Hide secret configuration and personal data.
- [ ] Capture a clean browser window, readable zoom, and clear narration.
- [ ] Keep final video under three minutes and publish publicly on YouTube as required by current event rules.
- [ ] Confirm audio, captions/accessibility, public visibility, and link playback in a signed-out browser.
- [ ] Add public YouTube URL to Devpost and submission report.
